# Persist resumable conversation history

Froe will keep one resumable conversation per Workspace by persisting the provider's continuation items in an owner-only JSON file at `$XDG_STATE_HOME/froe/conversations/<sha256(workspace)>.json`, or `~/.local/state/froe/conversations/` by default. Interactive CLI conversations load that file before provider construction and save it after every completed run through an adapter wrapper in the composition root; one-shot task invocations remain stateless. The file is keyed by Workspace so conversations never bleed across projects, and it lives outside the Workspace because continuation items include source-bearing tool output and model text. Attached image bytes are stripped on export because they belong only to the invocation that supplied them. A `/new` conversation command resets the provider's in-memory continuation and clears the file, extending the published `FroeSession` with an optional `resetConversation` operation and the provider-neutral `ModelProvider` seam with an optional `resetContinuation` operation. Persistence is best-effort: a failed write is swallowed so it cannot turn a completed run into a reported failure, and a missing, unreadable, or foreign history file starts a fresh conversation. This deliberately accepts that the local history file retains the same source-bearing context the model already saw, in exchange for cross-invocation continuity without server-side response storage.
