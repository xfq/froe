# Add localized skip navigation to articles

Keyboard users must currently tab through repeated site navigation before reaching an article's main content.

During article assembly, insert a skip link as the first body child. It should target the first `h1`, reuse a suitable existing id or assign a unique one, and display a localized label from the boilerplate-text dictionary. Add a non-empty translation to every existing locale dictionary. The link must stay off-screen during normal use and become clearly visible when focused.

Do not hard-code one language in the structure script. Verify keyboard behavior in English, Simplified Chinese, and at least one right-to-left article.
