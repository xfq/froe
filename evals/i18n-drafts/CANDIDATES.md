# Candidate tasks

These are real problems worth evaluating after their acceptance criteria and graders are stable enough for repeated comparison.

## RESP-02 — Complete responsive article layouts

The current shared article stylesheet still lacks a complete mobile treatment, and many article pages do not declare a viewport. Before activation, select representative page fixtures for dense tables, side notes, bidi content, and long code; define overflow assertions; and capture approved 390px and 1280px reference images.

## CODE-02 — Define long inline-code wrapping

Issue 464 concerns code and preformatted content that can overflow. Before activation, decide which inline and block contexts may wrap, how copy/paste fidelity is preserved, and which multilingual fixtures demonstrate the intended behavior. This should remain exploratory until those product decisions are explicit.
