0.3.0

Published September 1, 2026 · npm package @xfq/froe

Install npm install --global @xfq/froe@0.3.0

New features

  • Resumable conversation history: interactive sessions persist the conversation's model context per Workspace in an owner-only JSON file at $XDG_STATE_HOME/froe/conversations/, or ~/.local/state/froe/conversations/ by default. The next froe invocation in the same directory restores it, so you can close the terminal and continue later; /new clears the stored context and starts a fresh conversation. Attached image bytes are stripped from the stored file, one-shot task invocations never load or update it, and a missing, unreadable, or foreign file starts a fresh conversation.

Internal

  • The macOS sandbox violation monitor waits for expected denial events instead of relying on a fixed flush delay, making non-zero command exits more reliable on CI.

0.2.1

Published August 30, 2026 · npm package @xfq/froe

Install npm install --global @xfq/froe@0.2.1

New features

  • Froe core becomes a public library: @xfq/froe/core exports openFroeSession, configureFroe, and a typed FroeSession interface with ordered events and an approval adapter.
  • New summarizeAction and redactSensitiveText helpers give graphical and other presentation adapters safe, credential-redacted action summaries.

Internal

  • The CLI and conversation handling were refactored onto the same unified FroeSession interface, removing the separate conversation path.

0.2.0

Published August 30, 2026 · npm package @xfq/froe

Install npm install --global @xfq/froe@0.2.0

New features

  • MCP servers: register local stdio servers (froe mcp add <label> -- <command>) or remote Streamable HTTP endpoints (--url), with namespaced tools such as mcp__context7__resolve-library-id and a /mcp slash command that lists active servers. Tool calls support cancellation.
  • Web search: save a Tavily API key once with --configure-tavily and let the model search current external documentation through the web_search action.
  • Model selection: choose an OpenAI-compatible model per conversation with /model, or set model in configuration.
  • Automatic updates: npm-managed global installs check for a newer stable release at most once every 24 hours. Source checkouts and npx runs are never modified, and --no-update skips the check.
  • Server-side context compaction with a configurable compactThresholdTokens (or null to disable), recording a safe context_compacted event with only item counts and the threshold.
  • Additional directories: repeatable --add-dir <path> grants a run read and write access to named directories outside the Workspace.
  • Image attachments: repeatable --image <path> attaches PNG, JPEG, WEBP, or GIF files to the first prompt.
  • macOS Seatbelt sandbox hardening: spawned commands read only the Workspace, declared additional directories, their temporary directory, required system runtime locations, and the resolved Node toolchain; network access is denied and the child receives a temporary home directory.
  • froe --version prints the installed package version.
